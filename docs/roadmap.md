# Roadmap (fora do MVP)

- UI web e extensão IDE
- pausa e retomada interativa universal
- embeddings e banco vetorial
- leitura de PDFs
- geração de pull requests, edição **autônoma** de código (sem revisão humana) e execução de testes por agente — a edição *com* proposta e aprovação já existe (`devmate edit`/`docs`/`refactor`)
- múltiplos agentes, sincronização em nuvem e suporte a organizações
- plugins MCP e aplicativo móvel
